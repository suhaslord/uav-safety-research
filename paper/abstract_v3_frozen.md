# Abstract Draft — Frozen V3 Stage

Autonomous landing systems can fail when perception remains internally consistent while being systematically wrong. This simulation-only study investigates whether an independent, imperfect state estimate can help a safety layer detect persistent visual bias without becoming so conservative that it simply aborts most landings. AegisLand was evaluated across five synthetic perception-stress profiles using paired Monte Carlo trials. Earlier versions showed two complementary failure modes: a static risk-threshold supervisor substantially reduced unsafe touchdowns by aborting excessively, while a temporal supervisor restored availability but remained unable to identify persistent visual bias. A frozen third architecture introduced an independent lower-rate reference estimate, persistent cross-estimator bias estimation, confidence-gated correction, and redundant state fusion. In a held-out evaluation of 10,000 simulated landing episodes, the primary mixed-degradation unsafe-touchdown rate fell from 84.2% for the baseline and 84.0% for the temporal V2 architecture to 2.4% for V3, while V3 achieved a 97.6% success rate and 0% abort rate. Under occlusion, unsafe touchdowns fell from 34.6% for baseline to 1.4% for V3, with 98.6% successful landings. V3 preserved 100% success in clean, blur, and low-light profiles in the frozen run. These results support the hypothesis that independent error structure can expose persistent bias that is not identifiable from a single corrupted observation stream in this simulation. The study does not establish real-world UAV safety; the perception failures, reference estimator, and planar vehicle model are synthetic and require validation under more realistic sensing and dynamics.
