Hardware-free pilot · 10 October 2026

The simulator ran.
The detector was weak.

A hosted, headless Crazyflie Webots experiment injected single-motor failures and preserved every trace. It shows AegisLand can run this software study without bench access—and that the first motor-isolation model is not ready to trust.

Frozen pilot protocol

Three seeds. Five actuator states. Raw traces retained.

The run used a pinned open Crazyflie Webots plant and a deterministic command profile. The experiment changes the controller wrapper to inject a motor-command loss; it is not the paper's plant or training method.

01 / Scenarios

15 complete trajectories

For command seeds 11, 23, and 47: one healthy case and a complete loss of motor 1, 2, 3, or 4. The fault begins at 10 seconds in each 24-second run. Every trace contains 750 samples.

02 / Inputs

Motion and commanded motors

Each sample includes simulated position, three-axis angular rate, and four requested motor speeds. The faulted command is still logged as requested; motor application is separately zeroed.

03 / Split

Hold out the entire command seed

Ten trajectories from seeds 11 and 23 train the model. Five trajectories from seed 47 are held out. This avoids splitting adjacent windows from a single trace across both sets.

04 / Detector

Small five-class MLP

A NumPy network uses 100-sample windows with stride 20, one 24-unit hidden layer, and 80 Adam epochs. It is an independent baseline, not the paper's method or a recovery controller.

330 training windows→165 held-out windows→one exploratory score

Evidence boundary

A software milestone, not a flight claim.

Established

A hosted workflow can generate seeded headless Webots traces, fit the pilot model, and preserve predictions, weights, settings, and hashes without a physical aircraft.

Not established

Reliable motor isolation, detection latency, recovery, learned control-barrier performance, PX4/Gazebo behavior, flight safety, or a faithful reproduction of the cited paper.

Still separate

This study does not change the camera evidence, the frozen landing-controller results, or Phase 26's NO_DATASET_ADMITTED status. It is not wired into Model VASE.

Why the score is preliminary: the holdout contains one trajectory per class and overlapping windows. The result should guide a larger trajectory-level study; it cannot estimate generalization. The next gate is a faithful source/weights decision or a clearly labelled independent reproduction, followed by a larger predeclared seed holdout.
