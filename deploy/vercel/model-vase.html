AegisLand / landing perception

Can it tell when a landing estimate is wrong?

The frozen simulator found a recovery signal. The real-camera detector still fails under harder conditions.

Answer so far

Yes in one frozen planar simulation. Not yet from real camera input.

The two results come from separate systems. No end-to-end camera-to-landing model has been evaluated.

Model VASE is a system architecture, not a newly trained vision network.

It brings the research into one design. The individual components have not yet been evaluated together, so the combined system has no measured result.

What would change the answer

Connect the camera to the reliability test.

Recover the exact Phase 23 checkpoint and runtime, then build a preregistered test that links image detections, uncertainty, and the landing decision on independent imagery.

  • Do not use the reused 86-frame set to choose a reliability threshold.
  • Keep simulation, detector, and end-to-end results labeled separately.
  • Do not turn benchmark performance into a flight-safety claim.
