New · audited landing-perception finding · Phase 25

The most confident box
can still be wrong.

On the same 86 reused KIOS frames, Phase 23 had a correct detection somewhere in 43 occlusion views—but its highest-confidence box was correct in only 23. Under mixed stress, the counts were 44 versus 22.

Only two source video sessions were used. This is not a calibrated flight-safety probability.

The noise is added offline; these simulations do not demonstrate real-world flight safety.
