Key caution

An old estimate can become less accurate without showing much more uncertainty. A predictable residual does not mean the delay improved accuracy.

Review Phase 16 →

Main conclusion

The estimate gets worse. Confidence barely moves.

Later tests found patterns in the residuals. Those patterns did not undo the error in the estimate itself.

Research question

Does the uncertainty match the error?

We compare three things: the actual error, the reported uncertainty interval, and how the residual changes from one step to the next.
